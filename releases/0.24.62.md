# Versión 0.24.62 (web)

**Fecha:** 26 de noviembre de 2026

## Guardar las filas sin todos sus obligatorios, también como comportamiento

- Además de la acción de flujo «dejar guardar las filas sin todos sus obligatorios», ahora se puede configurar de fondo para toda la actividad. Se hace en Module › Flujos › Comportamientos: se elige la tabla y se enciende **«Guardar las filas sin todos sus obligatorios»**.
- Con eso, desde que se abre la actividad, a una fila incompleta el aviso le ofrece «Guardar de todos modos» en vez de descartarla. No hace falta escribir una regla.
